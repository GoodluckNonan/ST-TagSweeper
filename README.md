# 一鍵去正則保正文（ST-TagSweeper）

把聊天檔案裡 `<think>`、`<summary>`、`<plot>` … 這類標籤**直接刪掉、只留正文**的 SillyTavern 擴展。

刪除是破壞式地寫回聊天檔案本體，之後正則開著或關著、換哪個預設，都不會再看到那些內容炸在聊天框裡。

---

## 一、安裝

酒館 → **擴展（Extensions）** → **Install extension** → 貼上本專案的 GitHub 網址 → Install，
然後重新整理頁面（F5）。

安裝完到 **擴展** 面板確認出現「一鍵去正則保正文」，點開即可使用。之後在擴展清單按「Update」就能更新。

### 移除

刪掉 `public/scripts/extensions/third-party/ST-TagSweeper/` 資料夾，重新整理頁面即可。
插件產生的設定與備份點會留在酒館的使用者設定裡，可在「設定 → 恢復出廠設定」清掉。

---

## 二、操作流程

打開面板的方式：

* 輸入框旁邊的 **魔法棒 🪄 → 一鍵去正則保正文**；
* 快捷鍵 **`Ctrl + Alt + X`**（可自訂）；
* 擴展設定裡的「開啟面板」。

面板上方四個按鈕：**掃描 / 一鍵清除 / 回滾上次 / ?**。

> 掃描讀的是聊天檔案裡的原始內容，跟按鉛筆打開的編輯框是同一份資料。
> 所以**不需要關掉正則**，掃描與清除的結果都一樣。

### 1️⃣ 標籤處理

按「掃描」後，這裡列出這份聊天裡偵測到的每一種角括號標籤。每列左邊兩個框：

| 框 | 意思 |
| --- | --- |
| 🔴 紅框 | **消除**：連標籤裡的內容一起刪掉 |
| 🟢 綠框 | **加入白名單**：保留內容，只脫掉 `< >` 外殼 |
| 都不勾 | **不理會**：原樣留在訊息裡 |

紅框預設勾選（除了白名單，其他全刪）。點綠框會自動取消紅框，反之亦然。

每列後面顯示出現次數、`成對 / 孤兒開 / 孤兒閉`，以及原文樣本——不認識的標籤先看樣本再決定。

* **▸ 看它來自哪裡**：展開後列出這個標籤出現在哪幾條訊息，點編號跳到那一條。
* **👁 隱藏**：不想看到的標籤收起來。隱藏只影響顯示，處理規則完全不變。
* **顯示已隱藏**：把隱藏的叫回來。
* **批次隱藏**：先輸入關鍵字篩選，再按「隱藏列出的」。

### 2️⃣ 外殼

角括號不是唯一會被模型拿來當包裝的東西。這一頁可以管理其他成對符號：

| 外殼 | 預設 |
| --- | --- |
| `< >` | **啟用**（插件核心，不可刪除，可關閉，固定用 `/` 收束） |
| `{ }`、`[ ]`、`《 》`、`【 】` | 內建、預設停用，打勾即啟用 |

* 可以自己新增任何左右界（例如 `「 」`、`* *`）；
* 非 `< >` 的外殼可以選**是否用 `/` 收束**：開啟後，右界必須是 `/` + 右界符號才算結尾
  （例如 `«內容/»`）；關閉則直接以右界符號收尾；
* 每種外殼可選處理方式：**連內容一起消除** 或 **只脫殼、保留內容**；
* 外殼一樣會跳過程式碼區塊，不會把範例程式碼清掉。

**完全匹配移除**：在下方輸入框填入字串（例如 ` ```bash `、` ``` `、`<br>`），
只要訊息裡原樣出現這段文字，清理時就順帶刪掉。這一段不理會程式碼保護——填了就刪。

### 3️⃣ 預覽

一次顯示一條訊息，框上是標題，右上是 `‹ N / M ›` 翻頁按鈕。

* **顯示刪除內容**：圓角按鈕，亮起時顯示刪除前的原文，<span style="color:#e0554b">紅色刪節線</span>
  的部分就是等一下會被刪掉的內容；熄滅時顯示清理後的結果。
* **手動編輯內容**：直接編輯這一條清理後的結果。編輯狀態下文字框上方有
  **撤銷 / 重做 / 保存 / 取消**（也支援 `Ctrl+Z`、`Ctrl+Y`、`Ctrl+S`）。
  編輯框預設顯示紅色刪節線，紅線可以直接用退格刪掉；保存後這一條就以你改的內容為準，
  取消則完全不留痕跡。編輯中切換分頁時，會先問你要不要保存再切換。

標記「⚠ 可能誤刪正文」的訊息＝這一條有超過 95% 的內容會被清掉，很可能連正文一起刪了。

### 4️⃣ 一鍵清除

1. 重新掃描一次（避免用到過期的預覽）；
2. 跳出二次確認視窗，列出將改寫的訊息數、刪除字數與逐條對照；
3. 若有「可能誤刪正文」的訊息，會再問一次：「檢測到正文 #12 可能被誤刪，是否仍然繼續清除？」按「是」繼續、按「否」整個取消；
4. 自動建立備份點；
5. 寫入聊天檔案 → 重新載入 → 回讀校驗。

### 5️⃣ 回滾

* 面板上的 **回滾上次**；
* 或到「設定 → 備份點」，對任何一個備份點按「回滾」；
* 備份點可以下載成 `.jsonl`（酒館原生聊天檔格式），也可以從外部匯入。

回滾前會再自動備份一次「當前狀態」，所以回滾本身也能反悔。

## 三、白名單規則

白名單＝**保留內容、只脫外殼**：

| 輸入 | 白名單 | 結果 |
| --- | --- | --- |
| `<plot>正文</plot>` | `plot` | `正文` |
| `<plot>正文</plot>` | — | （整段刪掉） |
| `<!-- 2.正文 -->` | `!--` | `2.正文` |
| `<!-- 2.正文 -->` | — | （整段刪掉） |

* 標籤名比對不分大小寫，也支援中文標籤名（例如 `<正文>`）；
* 註解一律用 `!--` 當作名字（代表所有 HTML 註解）；
* 巢狀也處理：`<plot>前<think>推理</think>後</plot>` + 白名單 `plot` → `前後`；
* **白名單內容永久保護**（固定規則）：被列為白名單的標籤，內容永遠不會被消除，
  不管外面還包了幾層：

  | 輸入 | 白名單 | 結果 |
  | --- | --- | --- |
  | `【<a><story>正文</story></a>】` | `story` | `【正文】` |
  | `<a><b><c><story>正文</story></c></b></a>` | `story` | `正文` |
  | `<think>外<plot>內</plot>尾</think>` | `plot` | `內` |

  外層的垃圾標籤本身還是會刪；白名單**內部**的非白名單標籤照樣會刪
  （`<plot>正文<think>推理</think>尾巴</plot>` → `正文尾巴`）。
* 內建預設白名單：`plot`、`content`、`正文`。

## 四、破損標籤

模型偶爾會輸出少了開頭的標籤：

```
（前面一大段內容）
</think>
<plot>
正文
</plot>
```

處理規則：

* **成對標籤** → 刪掉 `<tag>` 到 `</tag>` 之間的全部內容；
* **落單的結尾 `</tag>`** → 連同它前面的那一段一起刪（預設）；
* **落單的開頭 `<tag>`** → 刪到下一個標籤之前或訊息結尾（可在設定切換）。

### 刪除起點從哪裡算

推理中間常常還夾著落單的 `<Admin>` 這類殘骸。若只刪到「上一個標籤為止」，
殘骸會把刪除範圍一刀切斷，讓它前面的內容整段留下來。預設的作法是
**往回找最近一個已經完整收尾的標籤**，中間落單的殘骸一律視為破損內容一起吸收。

三種模式在「設定 → 安全防護 → 要從哪裡開始砍」切換：

| 模式 | 行為 | 適用 |
| --- | --- | --- |
| **上一個已完整收尾的標籤**（預設） | 跳過落單殘骸往回找邊界，找不到就從訊息開頭砍 | 絕大多數情況 |
| 一律從訊息開頭砍 | 最激進，孤兒標籤前面的東西全清 | 確定前半段全是垃圾時 |
| 只砍到上一個標籤 | 最保守，容易被殘骸切斷 | 想逐條確認時 |

### 殘留警告

只要孤兒標籤的刪除範圍前面還留著沒被清掉的內容，插件會主動回報：

* 預覽頁該條訊息出現 `⚠ 前面可能還有殘留` 標籤；
* 上方摘要顯示「殘留警告 N 條」；
* 二次確認視窗也會提醒。

看到警告就切到「顯示刪除內容」確認一下，必要時把判斷方式改成「一律從訊息開頭砍」再清一次。

### 其他防護（預設開啟）

* **跳過程式碼區塊**：``` … ``` 裡示範用的 `<div>` 不會被誤刪；
* **整理空行**：刪完不會留一堆連續空行；
* **不動沒有標籤的訊息**。

| 分類 | 項目 | 說明 |
| --- | --- | --- |
| 掃描範圍 | 包含用戶消息 | 關掉就只清 AI 的消息 |
| | 包含系統消息 | `/sys` 之類 |
| | 同時清理所有 swipe 分支 | 避免切換 swipe 又冒出標籤（預設開） |
| | 同時清理思維鏈欄位 | 處理 `extra.reasoning`（預設關） |
| 安全防護 | 跳過程式碼區塊 / 行內 code | 預設跳過程式碼區塊 |
| | 整理空行 | 預設開 |
| | 白名單內容永久保護 | 固定開啟 |
| | 落單結尾標籤的處理方式 | 連內容刪 / 只刪標籤 / 不動 |
| | └ 要從哪裡開始砍 | 智慧判斷（預設）/ 從訊息開頭 / 只到上一個標籤 |
| | 落單開頭標籤的處理方式 | 刪到下一個標籤 / 刪到結尾 / 只刪標籤 / 不動 |
| 正則 | 暫時關閉所有正則 | 選用；手動按鈕，隨時可還原 |
| 快捷鍵 | 啟用 / 自訂 | 預設 `Ctrl+Alt+X`，點輸入框直接按組合鍵即可錄製 |
| 面板 | 記住面板位置 | 面板可用標題列拖曳 |
| 備份點 | 保留份數 / 立即備份 / 匯入 / 回滾 | 預設保留 5 份，單份上限 1.5 MB |

## 七、常見問題

**Q：會不會把正文誤刪？**
A：有可能，尤其是破損的孤兒標籤。所以流程是：先看預覽（紅色＝會被刪的內容）才寫入，
寫入前自動備份，寫入後回讀校驗；出事就按「回滾上次」。被列為白名單的內容永遠不會被消除。

**Q：清單上沒看過的標籤是哪來的？**
A：清單是整份聊天檔案統計出來的。點每列最左的 **▸** 可以看到它出現在哪幾條訊息（點編號可跳過去）。
不想看到就按 **👁** 隱藏（照樣會刪除）。

**Q：可以只清某幾條訊息嗎？**
A：目前是整份聊天一次處理。想保留某種標籤的內容就加白名單；想整條訊息都不動，
就把那個標籤設成「不理會」，或在預覽頁用手動編輯改成你要的樣子。

**Q：備份點存在哪？**
A：存在酒館的使用者設定裡（`extension_settings`），預設保留 5 份、單份上限 1.5 MB；
太大的備份會自動改成下載成檔案。酒館自己也會在 `data/<使用者>/backups/` 留聊天備份。

**Q：支援群組聊天嗎？**
A：支援，會逐條顯示發言者名字。
