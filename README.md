# 一键去正则保正文（ST-TagSweeper）

**简体中文** ｜ [繁體中文](README.zh-TW.md) ｜ [English](README.en.md)

把聊天档案里 `<think>`、`<summary>`、`<plot>` … 这类标签**直接删掉、只留正文**的 SillyTavern 扩展。

删除是破坏式地写回聊天档案本体，之后正则开着或关着、换哪个预设，都不会再看到那些内容炸在聊天框里。

---

## 一、安装

酒馆 → **扩展（Extensions）** → **Install extension** → 贴上本项目的 GitHub 网址 → Install，
然后重新整理页面（F5）。

安装完到 **扩展** 面板确认出现「一键去正则保正文」，点开即可使用。之后在扩展清单按「Update」就能更新。

### 移除

删掉 `public/scripts/extensions/third-party/ST-TagSweeper/` 文件夹，重新整理页面即可。
插件产生的设置与备份点会留在酒馆的用户设置里，可在「设置 → 恢复出厂设置」清掉。

## 二、操作流程

打开面板的方式：

* 输入框旁边的 **魔法棒 🪄 → 一键去正则保正文**；
* 快捷键 **`Ctrl + Alt + X`**（可自定义）；
* 扩展设置里的「打开面板」。

面板上方四个按钮：**扫描 / 一键清除 / 回滚上次 / ?**。

> 扫描读的是聊天档案里的原始内容，跟按铅笔打开的编辑框是同一份数据。
> 所以**不需要关掉正则**，扫描与清除的结果都一样。

界面文字可在「设置 → 界面语言」切成 **跟随酒馆 / 繁體中文 / 简体中文 / English**，
只影响界面，不影响清除结果。

### 1️⃣ 标签处理

按「扫描」后，这里列出这份聊天里检测到的每一种角括号标签。每列左边两个框：

| 框 | 意思 |
| --- | --- |
| 🔴 红框 | **消除**：连标签里的内容一起删掉 |
| 🟢 绿框 | **加入白名单**：保留内容，只脱掉 `< >` 外壳 |
| 都不勾 | **不理会**：原样留在消息里 |

红框默认勾选（除了白名单，其他全删）。点绿框会自动取消红框，反之亦然。

每列后面显示出现次数、`成对 / 孤儿开 / 孤儿闭`，以及原文样本——不认识的标签先看样本再决定。

* **▸ 看它来自哪里**：展开后列出这个标签出现在哪几条消息，点编号跳到那一条。
* **👁 隐藏**：不想看到的标签收起来。隐藏只影响显示，处理规则完全不变。
* **显示已隐藏**：把隐藏的叫回来。
* **批量隐藏**：先输入关键字筛选，再按「隐藏列出的」。

### 2️⃣ 预览

一次显示一条消息，框上是标题，右上是 `‹ N / M ›` 翻页按钮。

* **显示删除内容**：圆角按钮，亮起时显示删除前的原文，<span style="color:#e0554b">红色删节线</span>
  的部分就是等一下会被删掉的内容；熄灭时显示清理后的结果。
* **手动编辑内容**：直接编辑这一条清理后的结果。按下后文本框上方才会出现
  **撤销 / 重做 / 保存 / 取消**（也支持 `Ctrl+Z`、`Ctrl+Y`、`Ctrl+S`）。
  编辑框默认显示红色删节线，红线可以直接用退格删掉；保存后这一条就以你改的内容为准，
  取消则完全不留痕迹。编辑中切换分页时，会先问你要不要保存再切换。

标记「⚠ 可能误删正文」的消息＝这一条有超过 95% 的内容会被清掉，很可能连正文一起删了。

### 3️⃣ 外壳

角括号不是唯一会被模型拿来当包装的东西。这一页可以管理其他成对符号：

| 外壳 | 默认 |
| --- | --- |
| `< >` | **启用**（插件核心，不可删除，可关闭，固定用 `/` 收束） |
| `{ }`、`[ ]`、`《 》`、`【 】` | 内置、默认禁用，打勾即启用 |

* 可以自己新增任何左右界（例如 `「 」`、`* *`）；
* 非 `< >` 的外壳可以选**是否用 `/` 收束**：开启后，右界必须是 `/` + 右界符号才算结尾
  （例如 `«内容/»`）；关闭则直接以右界符号收尾；
* 每种外壳可选处理方式：**连内容一起消除** 或 **只脱壳、保留内容**；
* 外壳一样会跳过代码区块，不会把示例代码清掉。

**完全匹配移除**：在下方输入框填入字符串（例如 ` ```bash `、` ``` `、`<br>`），
只要消息里原样出现这段文字，清理时就顺带删掉。这一段不理会代码保护——填了就删。

### 4️⃣ 标签替换

在清理之前，先按你给的规则把文字换个名字。左边填要被换掉的字、右边填换成什么，按「新增替换」：

| 要换掉的 | 换成 | 结果 |
| --- | --- | --- |
| `<story>` | `<content>` | `<story>正文</story>` → `<content>正文</content>`，然后照 `content` 的白名单走 → `正文` |
| `[a]` | `[b]` | `[a]正文[/a]` → `[b]正文[/b]` |

* **改名发生在清理之前**，所以换完的新名字会照「标签处理 / 外壳 / 白名单」的规则处理；
* 当两边都是 `<名字>` 这种形式时，插件会**连结尾标签一起换**（`</story>` → `</content>`）；
* 规则按来源长度由长到短匹配，长字串优先，不会被短规则抢先；
* 只扫一趟，换过的文字不会又被下一条规则再换一次；
* 每列后面显示 `已替换 N 处` / `未命中` / `已停用`，摘要与预览页也会显示替换次数；
* 想暂时关掉某条规则，取消左边勾选即可；不想要了就按「删除」。

### 5️⃣ 一键清除

1. 重新扫描一次（避免用到过期的预览）；
2. 跳出二次确认窗口，列出将改写的消息数、删除字数与逐条对照；
3. 若有「可能误删正文」的消息，会再问一次：「检测到正文 #12 可能被误删，是否仍然继续清除？」按「是」继续、按「否」整个取消；
4. 自动建立备份点；
5. 写入聊天档案 → 重新加载 → 回读校验。

### 6️⃣ 回滚

* 面板上的 **回滚上次**；
* 或到「设置 → 备份点」，对任何一个备份点按「回滚」；
* 备份点可以下载成 `.jsonl`（酒馆原生聊天档格式），也可以从外部导入。

回滚前会再自动备份一次「当前状态」，所以回滚本身也能反悔。

## 三、白名单规则

白名单＝**保留内容、只脱外壳**：

| 输入 | 白名单 | 结果 |
| --- | --- | --- |
| `<plot>正文</plot>` | `plot` | `正文` |
| `<plot>正文</plot>` | — | （整段删掉） |
| `<!-- 2.正文 -->` | `!--` | `2.正文` |
| `<!-- 2.正文 -->` | — | （整段删掉） |

* 标签名比对不分大小写，也支持中文标签名（例如 `<正文>`）；
* 注释一律用 `!--` 当作名字（代表所有 HTML 注释）；
* 嵌套也处理：`<plot>前<think>推理</think>后</plot>` + 白名单 `plot` → `前后`；
* **白名单内容永久保护**（固定规则）：被列为白名单的标签，内容永远不会被消除，
  不管外面还包了几层：

  | 输入 | 白名单 | 结果 |
  | --- | --- | --- |
  | `【<a><story>正文</story></a>】` | `story` | `【正文】` |
  | `<a><b><c><story>正文</story></c></b></a>` | `story` | `正文` |
  | `<think>外<plot>内</plot>尾</think>` | `plot` | `内` |

  外层的垃圾标签本身还是会删；白名单**内部**的非白名单标签照样会删
  （`<plot>正文<think>推理</think>尾巴</plot>` → `正文尾巴`）。
* 内置默认白名单：`plot`、`content`、`正文`。

## 四、破损标签

模型偶尔会输出少了开头的标签：

```
（前面一大段内容）
</think>
<plot>
正文
</plot>
```

处理规则：

* **成对标签** → 删掉 `<tag>` 到 `</tag>` 之间的全部内容；
* **落单的结尾 `</tag>`** → 连同它前面的那一段一起删（默认）；
* **落单的开头 `<tag>`** → 删到下一个标签之前或消息结尾（可在设置切换）。

### 删除起点从哪里算

推理中间常常还夹着落单的 `<Admin>` 这类残骸。若只删到「上一个标签为止」，
残骸会把删除范围一刀切断，让它前面的内容整段留下来。默认的做法是
**往回找最近一个已经完整收尾的标签**，中间落单的残骸一律视为破损内容一起吸收。

三种模式在「设置 → 安全防护 → 要从哪里开始砍」切换：

| 模式 | 行为 | 适用 |
| --- | --- | --- |
| **上一个已完整收尾的标签**（默认） | 跳过落单残骸往回找边界，找不到就从消息开头砍 | 绝大多数情况 |
| 一律从消息开头砍 | 最激进，孤儿标签前面的东西全清 | 确定前半段全是垃圾时 |
| 只砍到上一个标签 | 最保守，容易被残骸切断 | 想逐条确认时 |

### 残留警告

只要孤儿标签的删除范围前面还留着没被清掉的内容，插件会主动回报：

* 预览页该条消息出现 `⚠ 前面可能还有残留` 标签；
* 上方摘要显示「残留警告 N 条」；
* 二次确认窗口也会提醒。

看到警告就切到「显示删除内容」确认一下，必要时把判断方式改成「一律从消息开头砍」再清一次。

### 其他防护（默认开启）

* **跳过代码区块**：``` … ``` 里示例用的 `<div>` 不会被误删；
* **整理空行**：删完不会留一堆连续空行；
* **不动没有标签的消息**。

## 五、设置项目

| 分类 | 项目 | 说明 |
| --- | --- | --- |
| 扫描范围 | 包含用户消息 | 关掉就只清 AI 的消息 |
| | 包含系统消息 | `/sys` 之类 |
| | 同时清理所有 swipe 分支 | 避免切换 swipe 又冒出标签（默认开） |
| | 同时清理思维链字段 | 处理 `extra.reasoning`（默认关） |
| 安全防护 | 跳过代码区块 / 行内 code | 默认跳过代码区块 |
| | 整理空行 | 默认开 |
| | 白名单内容永久保护 | 固定开启 |
| | 落单结尾标签的处理方式 | 连内容删 / 只删标签 / 不动 |
| | └ 要从哪里开始砍 | 智能判断（默认）/ 从消息开头 / 只到上一个标签 |
| | 落单开头标签的处理方式 | 删到下一个标签 / 删到结尾 / 只删标签 / 不动 |
| 正则 | 暂时关闭所有正则 | 选用；手动按钮，随时可还原 |
| 快捷键 | 启用 / 自定义 | 默认 `Ctrl+Alt+X`，点输入框直接按组合键即可录制 |
| 界面语言 | 跟随酒馆 / 繁體中文 / 简体中文 / English | 只影响界面文字 |
| 标签替换 | 规则随设置保存 | 每条规则可以单独启用 / 停用；改名先于清理 |
| 面板 | 记住面板位置 | 面板可用标题栏拖曳 |
| 备份点 | 保留份数 / 立即备份 / 导入 / 回滚 | 默认保留 5 份，单份上限 1.5 MB |

## 七、常见问题

**Q：会不会把正文误删？**
A：有可能，尤其是破损的孤儿标签。所以流程是：先看预览（红色＝会被删的内容）才写入，
写入前自动备份，写入后回读校验；出事就按「回滚上次」。被列为白名单的内容永远不会被消除。

**Q：清单上没看过的标签是哪来的？**
A：清单是整份聊天档案统计出来的。点每列最左的 **▸** 可以看到它出现在哪几条消息（点编号可跳过去）。
不想看到就按 **👁** 隐藏（照样会删除）。

**Q：可以只清某几条消息吗？**
A：目前是整份聊天一次处理。想保留某种标签的内容就加白名单；想整条消息都不动，
就把那个标签设成「不理会」，或在预览页用手动编辑改成你要的样子。

**Q：想保留 `<story>` 里的内容，但它不在白名单里怎么办？**
A：到「标签替换」页加一条规则，把 `<story>` 换成 `<content>`（白名单里有 `content`），
正文就会留下；也可以直接把 `story` 加进白名单，两种做法等价。

**Q：备份点存在哪？**
A：存在酒馆的用户设置里（`extension_settings`），默认保留 5 份、单份上限 1.5 MB；
太大的备份会自动改成下载成文件。酒馆自己也会在 `data/<用户>/backups/` 留聊天备份。

**Q：支持群组聊天吗？**
A：支持，会逐条显示发言者名字。
